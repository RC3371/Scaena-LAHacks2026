# Scaena Analytics Agent

Scaena Agent 3 reads booking conversations and turns them into strategy.

## Capabilities

- Auto-ingests Outreach and Gmail chat history.
- Extracts response patterns, venue-fit lessons, pricing signals, and next-step strategy.
- Summarizes booking-rate and response-rate performance.
- Helps the artist team improve future targeting and pitch angle.

## Example Prompts

- Analyze the latest outreach performance.
- What venues are responding best?
- What should the team change before the next pitch batch?
