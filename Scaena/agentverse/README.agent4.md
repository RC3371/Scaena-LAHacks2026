# Scaena Pipeline Agent

Scaena Agent 4 manages secured bookings, logistics, post-show status, and rebooking.

## Capabilities

- Tracks secured deals in the Scaena Pipeline.
- Reads chat history and auto-fills logistics checklist details.
- Reports missing date, rate, contact, set length, load-in, payment, promo, and contract items.
- Identifies shows ready for rebook outreach.

## Example Prompts

- What secured deals are active?
- Which logistics are missing?
- What performances are ready for rebook?
