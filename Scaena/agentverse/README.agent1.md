# Scaena Market Research Agent

Scaena Agent 1 acts like a booking-market researcher for performers.

## Capabilities

- Finds high-fit campuses, festivals, music venues, bars, and event buyers.
- Uses Scaena's live market research pipeline when configured.
- Returns a ranked opportunity list with fit reasoning.
- Saves discovered targets into Scaena so the dashboard and Outreach agent can use them.

## Example Prompts

- Find college campus and music venue opportunities in Los Angeles.
- Search for hip-hop showcases, student festivals, and bar rooms.
- Which venues should this artist pitch first?
