# GIG_BOTS Y2K Performer Dashboard

A Y2K styled, retro-futuristic dashboard tailored for performers (musicians, comedians, speakers) to monitor AI agents pitching venues and booking gigs.

## Features
- **Y2K Pop Aesthetic:** Bright neon colors (hot pink, cyan, yellow, purple), bubbly fonts, thick borders, heavy offset shadows, and entertainment-focused motifs (like early MTV/MySpace).
- **Agent Monitoring:** Real-time mock display of "Hype Bots" pitching playlists, podcasts, and venues.
- **Performance Visualization:** Chart.js integration customized with neon themes and sharp lines.
- **Responsive Layout:** Built with Tailwind CSS utilizing a robust CSS grid/flexbox foundation.

## Tech Stack
- React 18
- Tailwind CSS
- Lucide Icons
- Chart.js
