# Scaena Outreach Agent

Scaena Agent 2 writes and tracks booking outreach from the artist team's perspective.

## Capabilities

- Generates human, venue-specific booking pitches.
- Saves generated drafts into Scaena Outreach.
- Summarizes active outreach status and replies.
- Uses the artist's current profile, rate, genre, and venue fit.

## Example Prompts

- Generate a pitch for the best current venue.
- Summarize current outreach.
- What pitches are waiting for replies?
